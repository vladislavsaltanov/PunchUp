## Кратко о проекте
PunchUp - это 2D рогалик-платформер с пиксельной графикой. Вы оказываетесь в Башне - засекреченном объекте, из которого есть только один выход: подняться на самый верх и победить Тесея. Каждый забег генерируется заново, поэтому ни один из них не будет похож на предыдущий.
По пути вас ждут две секции - Лаборатория и Виварий, каждая со своей атмосферой и набором врагов. Сражаясь с ними, вы собираете предметы четырёх тиров редкости - от обычных до легендарных - которые накапливаются и постепенно меняют стиль игры. На нечётных этажах появляется магазин, где можно потратить внутриигровую валюту на дополнительное снаряжение.
Чем дольше идёт забег, тем сильнее и живучее становятся все враги - так что медлить не стоит. В конце вас ждёт Тесей. Подробнее о лоре и персонажах - в вики.

## Идея проекта
**Рикки** - не просто енот. Он - бывший экспериментальный объект секретной **лаборатории**, которая находится в башне. Его генетически модифицировали для максимальной скорости, рефлексов, способностей. Он не помнит **прошлое**, не знает, как он тут оказался, но хочет узнать, что произошло, а также **отомстить** за то, что с ним сделали. Для этого ему предстоит пробиваться по **этажам** лаборатории через взбесившихся агрессивных животных, которые тоже стали жертвами экспериментов неизвестного **ученого**. На пути Рикки может найти разные предметы и улучшения, которые помогут ему в финальной **схватке**. **Сможет** ли он узнать, кто стоит за этими экспериментами, сможет ли **отомстить** ему?

## Управление
### Основная схема управления для клавиатуры:
|    Действие   |    Клавиши    |
| ------------- |:-------------:|
| Передвижение влево-вправо     | `A` `D`     |
| Прыжок     | `Пробел`     |
| Удар      | `ЛКМ / Л`   |
| Дэш | `Shift` |
| Взаимодействие | `E` |

### Основная схема управления для геймпада:
|    Действие   |    Клавиши    |
| ------------- |:-------------:|
| Передвижение влево-вправо     | `Левый стик`     |
| Прыжок     | (PS4) `X` или (XBOX) `A`     |
| Удар      | (PS4) `▢` или (XBOX) `X`      |
| Дэш | `Нажатие на левый триггер` |
| Взаимодействие | (PS4) `△` или (XBOX) `Y`  |
